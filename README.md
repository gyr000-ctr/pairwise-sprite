# pairwise-sprite

## 题面（可直接粘贴）

精灵动画帧选择，支持可变帧时长与往返播放。约束：按每帧时长累加取模选帧；循环关闭时停末帧；ping-pong 到端点后反向；帧号始终落在 [0, frames)；1e12 秒时间戳不得丢精度；10 万次取帧不超过 100 ms；帧数为 0、fps 或时长非法、负时间要给出可区分的错误；取帧必须无状态、并发安全。验收：python -m pytest tests -q -k frame。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 大时间戳
- 并发
- 浮点边界
- 回绕
- fps 非整数

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线）。
